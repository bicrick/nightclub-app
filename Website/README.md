# NightCrew Website

A modern, responsive landing page for NightCrew - a premium nightclub table reservation and bill-splitting app.

## Overview

NightCrew is designed to revolutionize nightlife experiences by providing seamless table reservations, group coordination, and automatic bill splitting for premium venues. This website serves as the marketing landing page and showcases the app's key features and value propositions.

## Project Structure

```
Website/
├── index.html          # Main HTML structure
├── styles.css          # Complete CSS styling with animations
├── script.js           # Interactive JavaScript functionality
└── README.md          # This documentation
```

## Technical Implementation

### HTML Structure
- Semantic HTML5 with proper accessibility
- Responsive design with mobile-first approach
- Clean, organized section layout

### CSS Features
- **Modern Design System**: Purple/pink gradient theme with dark backgrounds
- **Responsive Design**: Mobile-first approach with tablet and desktop breakpoints
- **Advanced Animations**: 
  - Smooth scroll effects
  - Intersection Observer animations
  - CSS keyframe animations for interactive elements
  - Hover effects and micro-interactions
- **Component-Based Architecture**: Reusable classes for cards, buttons, and layouts

### JavaScript Functionality
- **Smooth Scrolling**: Navigation anchor links with smooth scrolling behavior
- **Scroll Effects**: Dynamic navbar background on scroll
- **Intersection Observer**: Fade-in animations for sections as they enter viewport
- **Interactive Elements**: 
  - Button ripple effects
  - Animated number counters
  - Dynamic content loading
- **Mobile Optimization**: Touch-friendly interactions and responsive behavior

## Design System

### Color Palette
- **Primary**: Purple gradient (`#8a2be2` to `#ff1493`)
- **Background**: Dark gradients (`#0a0a0a` to `#1a0f2e`)
- **Text**: White primary, light gray secondary (`#cccccc`)
- **Accent Colors**: Green for success (`#00ff88`), Red for urgency (`#ff6b6b`)

### Typography
- **Font Family**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700
- **Responsive scaling**: Fluid typography that scales with screen size

### Interactive Elements
- **Buttons**: Gradient backgrounds with hover animations
- **Cards**: Subtle borders with hover lift effects
- **Mockups**: Realistic phone and interface representations
